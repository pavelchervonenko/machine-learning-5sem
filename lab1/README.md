# Лабораторная работа 1

Линейная регрессия: реализация с нуля, анализ данных и улучшение качества
модели с помощью инженерии признаков и кросс-валидации.

---

#### **lab1.ipynb**
- исследовательский анализ данных (EDA);
- реализация линейной регрессии `LinearRegressionCustom`:
  - аналитическое решение;
  - градиентный спуск (GD);
  - стохастический градиентный спуск (SGD);
- реализация метрик `MSE`, `MAE`, `R²`, `MAPE`;
- генерация полиномиальных признаков и отбор по корреляции;
- нормализация признаков (z-score, min-max);
- k-fold и Leave-One-Out кросс-валидация;
- L2-регуляризация и подбор коэффициента по CV;
- сегментированная линейная регрессия по уровню дохода;
- формирование предсказаний и Kaggle submission.

#### **datasets**
- `submission_kaggle_segment_blend.csv` — финальный файл для Kaggle.
- `train.csv` — обучающая выборка;
- `test.csv` — тестовая выборка.


> В качестве базовой модели используется собственная реализация линейной регрессии.
> Все этапы реализованы без применения готовых моделей `sklearn`.
