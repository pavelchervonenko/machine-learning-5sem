# Домашнее задание 3

#### **hw3-unsupervised.ipynb**
- загрузка и предварительная обработка датасета **Samsung Human Activity Recognition**;
- масштабирование признаков (`StandardScaler`);
- понижение размерности методом **PCA**:
  - выбор числа компонент по доле объяснённой дисперсии (≥ 90%);
  - визуализация выборки в первых двух главных компонентах;
- кластеризация:
  - `KMeans` из `sklearn` и собственная реализация;
  - агломеративная кластеризация (`AgglomerativeClustering`, `linkage='ward'`);
  - применение метода локтя и оценка качества с помощью **Adjusted Rand Index**;
- классификация:
  - линейный SVM (`LinearSVC`) с подбором гиперпараметра `C` через `GridSearchCV` (cv=3);
  - сравнение качества на исходных признаках и после применения PCA;
- дополнительные методы:
  - понижение размерности с помощью **t-SNE**;
  - кластеризация в пространстве t-SNE с помощью **DBSCAN** и визуализация найденных кластеров.

### **data**
- файлы из датасета *Samsung Human Activity Recognition*  
  (`samsung_train.txt`, `samsung_train_labels.txt`,  
  `samsung_test.txt`, `samsung_test_labels.txt`) — матрицы признаков и метки активности,
  путь к ним задаётся в ноутбуке.
